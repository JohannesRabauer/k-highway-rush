# Highway Rush 🚗💨

Ein 3D-Auto-Runner-Spiel, entwickelt mit Three.js.

## 🎮 Spielen

▶️ [Auf GitHub Pages spielen](https://johannesrabauer.github.io/k-highway-rush/)

## 🕹️ Steuerung

| Plattform | Aktion |
|-----------|--------|
| **PC** | ← → Pfeiltasten oder A/D |
| **Handy** | Wischen oder Tippen (links/rechts) |
| **Pause** | ESC oder P |

## 🏎️ Features

- 5 einzigartige Autos (Rot, Türkis x2, Lila x2)
- 3 verschiedene Strecken (Stadt, Landschaft, Nacht)
- Prozeduraler Traffic mit Autos, LKWs und Motorrädern
- Dynamisch steigende Schwierigkeit
- Highscore-Speicherung (localStorage)
- Prozedural generierte Hintergrundmusik & Soundeffekte
- Vollständig 3D mit Three.js

## 🛠️ Technik

- Reines HTML5/CSS3/JavaScript – keine Build-Tools nötig
- Three.js r128 (CDN)
- Web Audio API für Musik & Sounds
- GitHub Actions → GitHub Pages Deployment

## 🚀 Lokal starten

```bash
# Einfach einen lokalen HTTP-Server starten:
python -m http.server 8080
# Dann http://localhost:8080 öffnen
```
